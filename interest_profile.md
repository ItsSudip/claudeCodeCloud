# Interest Profile

## About Me
I'm a software engineer and startup founder. I build data infrastructure and developer tools,
and I'm hands-on with LLM-based products. I read to make better technical and business
decisions, not to be entertained. I prefer primary sources, benchmarks, post-mortems and
first-hand founder write-ups over hot takes.

cheaper. Especially: model releases, inference cost reductions, database internals, systems

### Developer Tooling (weight: 0.8)
keywords: devtools, cli, docker, ci, build, testing, framework, library, sdk, api, open-sourced, github

### Saved for Later (weight: 0.6)
Long reads, primers and reference material worth a focused sitting rather than a skim.
